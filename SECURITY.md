# Security Policy

## Supported versions

Please report security issues affecting the latest version on `main` or the latest release.

## Reporting a vulnerability

Do not open a public issue for an undisclosed vulnerability. Send a description and reproduction steps privately to **calestinfisalia@gmail.com**. Include the potential impact, AniLayer and Windows versions, and evidence that does not contain sensitive data.

Please allow the maintainer reasonable time to investigate and address the issue before public disclosure. You will receive an acknowledgment and follow-up.
